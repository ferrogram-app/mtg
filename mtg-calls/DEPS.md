# Dependencies

## getrandom

The `random_id` of `phone.requestCall`.

## mtg-crypto

SHA-256 for `g_a_hash` and for the emoji fingerprint.

## mtg-secret

The Diffie-Hellman group checks, key exchange and `Key` (SHA-1 fingerprint): calls use the same
exchange as secret chats.

## mtg-tl-types

The API types and functions of the `phone.*` methods and the `updatePhoneCall` update.

## toml

Used to test that this file lists all dependencies from `Cargo.toml`.
